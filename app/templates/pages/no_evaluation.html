Aucune évaluation possible

Cela peut venir de deux choses :

  • le modèle n'a détecté aucun objet sur les images testées, et aucune correction n'a été faite ;
  • les images utilisées pour l'évaluation sont les mêmes que celles utilisées pour l'entraînement — les résultats ne seraient pas représentatifs.

Pour obtenir une évaluation pertinente, testez le modèle sur de nouvelles images. Vous pouvez aussi terminer le cycle sans rien ajouter à la vérité terrain : les images de test et leurs corrections seront archivées dans le projet.
